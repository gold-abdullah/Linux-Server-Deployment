## 🚀 Quick Overview

1. **System Maintenance:** Updated & upgraded Ubuntu Linux package repositories.
2. **Nginx Installation:** Installed and enabled Nginx HTTP web server daemon.
3. **Service Verification:** Checked active service status and tested start/stop/restart commands.
4. **Localhost Deployment:** Customized `/var/www/html/index.html` with custom content and verified via browser and `curl http://localhost`.
